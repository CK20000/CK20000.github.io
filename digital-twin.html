nets:140 auto-classified sim:ngspice + Renode bus:ZeroMQ ui:PyQt6 · 7 viewers milestones:14

WHAT IT DOES

Auto-generates a complete ngspice netlist from any .kicad_pcb file, runs real STM32 firmware on a virtual MCU in Renode, and renders live physics — LED states, per-net currents, power dissipation, and 2D thermal diffusion — on the real board geometry.

Bidirectional: a Python control panel writes into Renode's memory bus exactly like an external field signal, propagating through firmware → SPICE → visualization in real time.

WHY IT'S PUBLIC

A free, open-source alternative to paywalled PCB simulators. No stubs, no hardcoded circuits, no faked inputs — every value on screen traces from a real KiCad component through compiled firmware through SPICE through heat diffusion.

THE PROBLEM

Existing PCB simulators are either paywalled, closed-source, or require manual circuit re-entry. No open tool connects a real KiCad layout to a running MCU firmware and produces physics-accurate analog simulation.

THE HARD PART

The simulation itself wasn't the challenge — generalization was. Making it work for any KiCad board (not just the one I designed) required solving netlist parsing, component classification, and automated model generation without hardcoded knowledge.

THE FIX

  • 143 components auto-classified with zero hardcoded knowledge — heuristics based on library ID (lib_id) and value patterns. Unknowns fall back to a black-box resistor with graceful degradation.
  • Trace resistance injected between regulator outputs and loads, computed from real copper geometry: R = ρ · L / (W · t) with ρ = 1.72e-8 Ω·m (copper at 20 °C), t = 35 µm (1 oz copper).
  • Source metadata layer maps every SPICE branch back to its KiCad net — no hardcoded net names anywhere in the pipeline. The solver reads metadata at runtime to know which net a current or voltage belongs to.

THREE ZMQ TOPICS, ONE BUS

  • 5557 — Renode observables (OBS), published by renode_reader.py
  • 5558 — Injections (INJECT), subscribed by renode_reader.py
  • 5556 — Simulation outputs (SIM, RAIL, POWER, CURRENT, NODE, DOUT, ...) from the solver

WHY ZMQ

Multiple viewers can subscribe to the same stream simultaneously; the control panel and the solver communicate without tight coupling. Every component is independently restartable without taking down the pipeline.

SEVEN LIVE VIEWERS

  • LED overlay — animated LED states on real PCB positions (D3–D9)
  • Trace resistance — per-trace Ω with hover inspection, extracted from copper geometry
  • Current flow — colored traces on top layer, real-time per-net current
  • Voltage map — per-net DC node voltages, viridis 0–12 V
  • Power dissipation — per-component heat map with log/linear colormaps
  • Thermal (θja) — per-component junction temperature
  • Thermal field v2 — 2D diffusion with 2-layer copper, vias as thermal bridges, FR4 substrate

UNIFIED DASHBOARD

All seven viewers, plus the control panel and the live pipeline console, embedded in a single PyQt6 window with tabs and a sidebar. Matplotlib animations are throttled based on the number of visible plots to keep CPU bounded.
