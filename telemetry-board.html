What it is

A custom PCB built to validate a high-speed observer system for motor state estimation. Integrates an MPU6050 IMU, HMC5883L magnetometer, VL53L0X time-of-flight sensor, plus direct interfaces for load cells and quadrature encoders — streaming timestamped sensor data to a host PC for real-time attitude estimation and load tracking.

Key features

  • Non-blocking C++ firmware — sensor polling loop not bottlenecked by communication
  • 84-byte binary payload — timestamped sensor data + state variables, packed and streamed over USB CDC
  • PySide6 dashboard — modular Python GUI with custom .qss styling for real-time plotting of rotation, current, IMU, and load metrics
  • KiCad schematic + PCB + BOM + CAD — full open-source hardware stack
