Motor Drivers

Two board designs — full-bridge prototype and isolated half-bridge PCB

Full-Bridge Prototype

Hand-wired full H-bridge built on perfboard before I designed any PCBs. Gate drivers, MOSFETs, deadtime handling, and current sense wired point-to-point. Ugly, but it worked — the build that proved the topology well enough to commit to a fabricated design.

Full-bridge prototype — hand-wired H-bridge, working.

Isolated Half-Bridge

First fabricated motor driver — a single isolated half-bridge. IR2101 gate driver with bootstrap topology, 6N137 optocoupler isolation between logic and power stages, and an AD8418 bidirectional current sense amplifier across a 2 mΩ shunt. The design language that later carried into the FOC driver boards.

  • IR2101 gate driver with bootstrap topology (1N5819 diode / 1 µF cap)
  • 2× 6N137 high-speed optocouplers isolating logic from power
  • AD8418 bidirectional current sense across 2 mΩ shunt, heavily filtered
  • Buffered 1.65 V reference rail via MCP6002 for center-biased sensing
  • 1000 µF bulk smoothing on the power rail
Isolated half-bridge — logic and power domains separated by optocouplers.
