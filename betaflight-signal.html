Betaflight Signal Processing Testbed

2025 · STM32G431 · DSP filter pipeline evaluation platform
mcu:STM32G431 rate:1 kHz payload:44-byte binary cordic:hardware gui:PySide6

What it is

An ultra-low-latency hardware testbed for evaluating Betaflight DSP filter pipelines on real flight-controller silicon. Runs the full C++ signal chain — PT1, PT2 cascaded, biquad Butterworth low-pass, and a dynamic biquad notch — on an MPU6050 IMU mounted on a single-axis motor arm.

Key features

  • Hardware CORDIC acceleration — single-cycle trig for biquad coefficient synthesis
  • 44-byte packed binary telemetry — magic-word locked (0xDDBBCCAA) at 1 kHz over USB CDC
  • Live FFT resonance analysis — Python-side FFT over rolling 1000-sample buffers to detect dominant vibration frequencies and mechanical harmonics
  • PySide6 reactive GUI — attitude estimation (Roll/Pitch/Yaw), pipeline group delay prediction, interactive parameter tuning at 4 Hz
